# Портфолио — Python-разработка и автоматизация

Telegram-боты, мониторинг цен, автоматизация и сайты под ключ.

## 🤖 [Telegram-бот онлайн-записи](01-booking-bot)
Полноценная запись клиентов для салонов, барбершопов и сервисов.
- Выбор мастера, услуги, даты и свободного времени; постоянных клиентов бот узнаёт сам
- **Автонапоминания** за сутки и за 2 часа, **оценка мастера** после визита
- **Админ-панель**: расписание, статистика и выручка, **выгрузка в Excel**, выходные дни

`Python` `aiogram 3` `SQLite` `openpyxl`

## 📊 [Мониторинг цен конкурентов](02-price-parser)
Каждый запуск собирает каталог, сравнивает цены с прошлым разом и присылает изменения в Telegram.
- **1000 товаров из 50 категорий за ~10 секунд** (параллельный сбор)
- История цен, Excel-отчёт с **графиком** и подсветкой подешевевшего и подорожавшего
- Пример отчёта: [report_demo.xlsx](02-price-parser/report_demo.xlsx)

`Python` `requests` `BeautifulSoup` `ThreadPoolExecutor` `openpyxl`

## 💈 [Лендинг барбершопа](03-landing) · [смотреть онлайн →](https://albert-devdev.github.io/portfolio/03-landing/)
Продающий сайт, связанный с ботом записи.
- **Живая анимация переписки с ботом** в макете телефона
- **Интерактивная запись прямо на странице**: услуга → мастер → день → время → итог
- Тёмная и светлая темы, анимации при прокрутке, адаптивность под телефон

`HTML` `CSS` `JavaScript`
