# Telegram-бот для записи клиентов

Полноценная онлайн-запись для барбершопов, салонов, автосервисов, репетиторов — любого бизнеса с записью по времени.
Клиенты записываются сами за 30 секунд, администратор не тратит время на звонки.

## Для клиента
- 💈 **Выбор мастера** → услуги → даты → свободного времени
- 📅 Показываются только дни, где есть окна, и сколько их осталось
- 📱 Номер телефона одной кнопкой («Отправить мой номер»)
- 🔁 **Постоянных клиентов бот узнаёт** и не спрашивает имя и телефон повторно
- ⏰ **Автоматические напоминания** за сутки и за 2 часа до визита
- ⭐ **Оценка мастера** после визита
- 🗂 Просмотр и отмена своих записей

## Для администратора (`/admin`)
- 📋 Расписание на сегодня и завтра с выручкой
- 📊 Статистика за 30 дней: записи, клиенты, выручка, средний чек, рейтинг, загрузка мастеров
- 📥 **Выгрузка всех записей в Excel** прямо в чат
- 🚫 Выходные дни: закрыть или открыть дату для записи в один клик
- 🔔 Мгновенные уведомления о новых записях, отменах и оценках

## Надёжность
- Двойная запись на одно время невозможна (ограничение на уровне базы данных)
- Прошедшее время и закрытые дни скрываются автоматически
- Напоминания не дублируются и переживают перезапуск бота

## Стек
Python 3.10+, aiogram 3, SQLite, openpyxl

## Структура
| Файл | Что внутри |
|---|---|
| `business.json` | Мастера, услуги, цены, часы работы клиента (образец — `business.example.json`) |
| `config.py` | Загрузка настроек; без `business.json` бот работает как демо-барбершоп |
| `bot.py` | Сценарий записи для клиентов |
| `admin.py` | Админ-панель, статистика, выгрузка |
| `reminders.py` | Фоновые напоминания и запрос оценок |
| `keyboards.py` | Кнопки и форматирование сообщений |
| `db.py` | Работа с базой данных |

## Запуск
```bash
pip install -r requirements.txt
cp .env.example .env   # впишите BOT_TOKEN и ADMIN_ID
python bot.py
```

## Под нового клиента — за 10 минут
Копируете `business.example.json` → `business.json`, вписываете мастеров, услуги, цены и часы. Код не меняется.
Как запустить бота клиенту на сервере круглосуточно — в [DEPLOY.md](DEPLOY.md).
