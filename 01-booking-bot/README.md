# Telegram-бот для записи клиентов

Бот для салонов, барбершопов, автосервисов, репетиторов — любого бизнеса с записью по времени.

## Возможности
- Выбор услуги с ценой, даты (на 7 дней вперёд) и свободного времени
- Занятые и прошедшие слоты скрываются автоматически, двойная запись невозможна
- Сбор имени и телефона с проверкой формата
- Мгновенное уведомление администратору о новой записи и отмене
- Клиент видит и отменяет свои записи: `/my`
- Администратор смотрит расписание на сегодня: `/today`

## Стек
Python 3.10+, aiogram 3, SQLite

## Запуск
```bash
pip install -r requirements.txt
cp .env.example .env   # впишите BOT_TOKEN и ADMIN_ID
python bot.py
```

## Как адаптировать под клиента
Услуги, цены и рабочие часы — в начале `bot.py` (`SERVICES`, `WORK_HOURS`).
