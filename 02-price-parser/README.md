# Мониторинг цен конкурентов → Excel + Telegram

Не просто парсер, а **система слежения за ценами**: каждый запуск собирает весь каталог,
сравнивает с прошлым разом и показывает, что подешевело и подорожало.
Запускается по расписанию (cron или Планировщик заданий Windows), например каждое утро.

Демо работает на [books.toscrape.com](https://books.toscrape.com), учебном сайте для парсинга:
**1000 товаров из 50 категорий собираются примерно за 10 секунд.**

## Что умеет
- ⚡ **Параллельный сбор**: несколько потоков, обход всех категорий и страниц
- 🕓 **История цен** в SQLite: каждый запуск сравнивается с предыдущим
- 📊 **Excel-отчёт из трёх листов:**
  - «Сводка»: ключевые цифры, таблица по категориям, **график средних цен**
  - «Товары»: весь каталог с тепловой шкалой цен, рейтингом ★★★★☆, фильтрами
  - «Изменения цен»: было/стало, разница в £ и %; подешевевшее зелёным, подорожавшее красным
- 🔔 **Уведомление в Telegram** со списком изменений (`--notify`)
- 🛡 Повторные попытки при сбоях сети, паузы между запросами (бережно к сайту)

## Запуск
```bash
pip install -r requirements.txt
python parser.py                        # весь каталог
python parser.py --categories 5         # быстрая проверка
python parser.py --notify               # + отправить изменения в Telegram (см. .env.example)
python parser.py --simulate-changes 20  # демо: имитировать изменения цен
```

Пример отчёта: [`report_demo.xlsx`](report_demo.xlsx). Изменения цен в нём смоделированы,
потому что на учебном сайте цены не меняются.

## Структура
| Файл | Что внутри |
|---|---|
| `parser.py` | Сбор данных, сравнение, запуск |
| `history.py` | История цен (SQLite) |
| `report.py` | Построение Excel-отчёта с графиком |

## Как адаптировать под заказ
Поменять `START_URL` и CSS-селекторы в `get_categories()` и `parse_cards()` под нужный сайт.
Перед парсингом чужого сайта проверьте его правила (robots.txt, пользовательское соглашение).
