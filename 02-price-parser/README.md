# Парсер каталога товаров → Excel

Собирает товары со всех страниц каталога и сохраняет в аккуратный Excel-файл:
название, цена, рейтинг, наличие, ссылка. Шапка оформлена, включены автофильтр и закреплённая строка.

Демо работает на [books.toscrape.com](https://books.toscrape.com) — учебном сайте для парсинга.

## Что умеет
- Обход пагинации до последней страницы
- Повторные попытки при сетевых ошибках, пауза между запросами (бережно к сайту)
- Выгрузка в `.xlsx`, готовую к фильтрации и сортировке

## Запуск
```bash
pip install -r requirements.txt
python parser.py --pages 50 --out books.xlsx
```

## Как адаптировать под заказ
Поменять `BASE_URL` и CSS-селекторы в `parse_page()` под нужный сайт.
Перед парсингом чужого сайта проверьте его правила (robots.txt, пользовательское соглашение).
